RAG优化

发表于2026-11-26|更新于2026-11-27
|浏览量:

RAG基本流程

RAG检索的基本流程分为两个阶段，在线阶段和离线阶段：

离线阶段

  • 🔵加载数据
  • 🔵切分数据为一个个知识片段
  • 用向量模型将知识片段🔵向量化，使得语意相近的文本在该向量空间中邻近
  • 将向量数据🔵存入向量数据库

在线阶段

  • 将用户的查询🔵问题进行向量化，需要🔵与离线阶段采用同一个向量模型
  • 🔵知识召回，将问题向量与向量库进行检索匹配，召回TopN
  • 将召回的知识与用户问题🔵组成新的提示词，生成回答

    但是只有基本的RAG检索流程还不够，很多时候AI的回答并不准确，检索准确率并不高，所以RAG还需要优化

RAG的优化

根据RAG的基本流程有以下方式进行优化：

查询优化

查询优化即对用户的查询问题进行优化，很多时候用户的问题会🔵过于口语化，🔵表达模糊不清，容易影响检索的准确率，所以需要对此进行优化使用户问题更加适合检索。常见的查询优化策略有：🔵查询重写，查询拆分，HyDE，查询路由

查询重写

用LLM将用户口语化的问题转化为更加规范的用语

查询拆分

有时候用户的问题涉及多个不同领域的知识，比较复杂，这时可以将用户的问题拆分成多个子问题，分别进行检索，最后再汇总

HyDE

HyDE的核心思想是，先让LLM根据用户的问题生成一个虚构的答案文档，再用这个虚构的答案文档去进行检索

查询路由

根据问题的类型（事实型，计算型，主观型）来决定走哪个rag，或者是直接LLM，或者是调用工具

检索优化

常见的检索手段有两种：

语义检索

语义检索也叫稠密检索，根据向量检索语义最相近的

关键词检索

关键词检索，也叫稀疏检索，基于关键词检索，关注关键词在文档中的权重，有两种实现：

  • 统计式：BM25等基于词频统计
  • 学习式：BGE-M3等基于神经网络模型训练
    两种检索方式各有优缺点：语义检索能够根据上下文理解同义词，近义词，即使有时候用户有模糊的表达或者有某个错别字也能正确检索，但是对罕见词、专有名词不太敏感；关键词检索能够精准的匹配关键词、专有名词，但是对词语的拼写极为敏感，比如汽车不等于轿车。

混合检索

所以最佳的方案是将两种检索方式结合起来，采用🔵多路召回+融合排序的方式：通过稀疏和稠密等多种方式分别查询文档列表，最后再将所有文档列表融合起来，最后将所有文档列表重新打分排序
而常见的融合的方式有：加权求和，RRF

加权求和

首先需要对分数进行归一化，然后对不同的召回方案设置不同的权重，最后合并分数。常见的归一化方法有：Min-Max,Z-Score,Softmax。

  • Min-Max：值范围固定为[0,1]，公式为 （score - min） / (max - min)，score为加权求和后总分
  • Z-Score：转为均值为0，标准差为1的正态分布。公式是 (s - avg) / 标准差
  • 将分数转为概率分布，所有值在 0~1 之间，且总和为 1，分布均匀程度取决于temperature
RRF

基于倒数排名求和，只与排名有关，与分数无关。公式：1/(k + rank)其中k为常量，通常为60

重排序

因为第一轮检索更重视快和召回率，他只负责把一些相关的文档给找到所以需要进行重排序来让文档的排序更加合理。重排序一般采用Cross Encoder交叉编码方式，即把用户的问题和召回的每个文档一起输入给Transformer模型，精确打分

RAG评估工具与指标

评估工具

在检索完后，还需要对这次召回进行评估来评判这次检索效果，常用的检索工具为RAGAS，只需输入一行命令即可安装

或者使用uv来进行安装

指标

ragas提供了六个核心指标，需要从生成质量和检索质量个维度来考察，以下为六个核心指标

Context Precision（上下文精度）

此指标得到的结果分数越高意味着召回的文档中与问题，相关性越强，检索效果越好，目标分数一般要大于等于0.85

Context Recall（上下文召回率）

使指标得到的结果分数越高意味着标准答案中包含的信息被召回的文档覆盖的越多，检索效果更好，目标分数一般要大于0.70

Context Entities Recall（事实上下文召回）

此指标得到的结果分数越高意味着标准答案中包含的实体（人名，地名，国家名），被召回的文档覆盖越多，目标分数一般要大于0.70

Faithfulness（忠实度）

此指标得到的结果分数越高意味着模型出现的幻觉越少，召回的文档与标准答案更加匹配，目标分数一般要大于0.90

Response Relevancy（回答相关性）

此指标得到的结果分数越高意味着模型回答的切题度越好，紧扣用户的问题，目标分数一般要大于0.88

Noise Sensitivity（噪声敏感度）

使指标得到的结果分数越低意味着模型产生错误，回答的频率越低，目标分数一般要小于0.10
